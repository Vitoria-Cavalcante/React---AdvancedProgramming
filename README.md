# Atividade React — Minha Loja

Página simples e responsiva feita com React, com 6 componentes:
Acordeão, Paginação, Barra de Progresso, Abas, Menu Suspenso e Notificação Toast.

Desafio extra: estado global com **Context API** (carrinho de compras e notificações), em `src/context/`.

Autoria: Loren Santos — Atividade React I.

## Como rodar

```bash
npm install
npm run dev
```

Depois abra http://localhost:5173 no navegador.
